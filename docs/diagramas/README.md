# Diagramas

- `red-fisica.png`: red propuesta (Figura 1 de la memoria). Fuente: `red-fisica.py`.
- `red-lab.png`: red del laboratorio (Figura 2). Fuente: `red-lab.py` (usa los iconos de `red-fisica.py`).
- `red-conmutacion.png`: switches, troncales, túneles y OSPF (Figura 3), con los nombres y direcciones de la maqueta `red/clab/`. Fuente: `red-conmutacion.py`.

Para regenerarlos: `python3 red-fisica.py` crea el `.svg`; se pasa a PNG abriéndolo en el navegador o con Playwright.
